# Linux权限_02
#### 1.修改文件权限
- chmod可以修改文件或者目录的权限
- u表示拥有者,user
- g表示所属组,group
- o表示other,其他用户
- a表示all,所有用户
- +表示增加权限
- -表示去掉权限
- =表示重新设置权限
- 例子:chmod u+x file,给拥有者增加可执行权限
- 例子:chmod g-w file,去掉所属组写权限
- 例子:chmod o=r file,让other只保留读权限

#### 2.权限的数字表示
- r表示读权限,对应数字4
- w表示写权限,对应数字2
- x表示执行权限,对应数字1
- 没有权限对应数字0
- 一组权限可以用数字相加表示
- rwx=4+2+1=7
- rw-=4+2=6
- r-x=4+1=5
- r--=4
- chmod 755 file表示拥有者rwx,所属组r-x,other r-x
- chmod 644 file表示拥有者rw-,所属组r--,other r--

#### 3.目录权限
- 文件的r表示可以读取文件内容
- 文件的w表示可以修改文件内容
- 文件的x表示文件可以被执行
- 目录的r表示可以查看目录里的文件名
- 目录的w表示可以在目录中创建,删除或者重命名文件
- 目录的x表示可以进入目录
- 对目录来说,x权限很重要,没有x权限就不能cd进入目录
- 删除文件看的是所在目录的写权限,不只看文件本身权限

#### 4.修改拥有者和所属组
- chown可以修改文件拥有者
- chgrp可以修改文件所属组
- 例子:chown user file,把文件拥有者改成user
- 例子:chgrp group file,把文件所属组改成group
- 例子:chown user:group file,同时修改拥有者和所属组
- 修改拥有者通常需要root权限

#### 5.默认权限和umask
- 新建文件和目录时,系统会自动给默认权限
- 普通文件默认最大权限一般是666,因为普通文件默认不带执行权限
- 目录默认最大权限一般是777
- umask会从默认权限中去掉一部分权限
- 查看umask:umask
- 常见umask是022
- 文件666减去022后通常得到644
- 目录777减去022后通常得到755

#### 6.总结
- 权限控制的是不同角色能不能读,写,执行目标
- chmod负责改权限
- chown负责改拥有者
- chgrp负责改所属组
- 目录权限和文件权限含义不同,尤其要注意目录的x权限
