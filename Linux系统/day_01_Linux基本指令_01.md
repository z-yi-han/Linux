## 指令
#### 1.clear
清屏
#### 2.pwd
显示用户当前所处的目录(路径)
#### 3.ls -'x'
ls是命令,x是命令行选项(可以是0个或多个,多个用空格隔开)
ls:查看文件名，显示当前文件属性中的文件名
ls -l:查看更多文件属性，也可以查看指定目录的内容
ls -a:显示隐藏文件
ls -a -l(ls -l -a && ls -la):两者操作都进行，组合使用，隐藏文件也显示   
ls -a -l -d:查看目录本身的文件
#### 4.touch
+文件名表示新建一个普通文件(文本文件)  
touch可以修改文件时间
#### 5.cd /xxxx....
更改目录,进行路径切换，路径改到...   
cd .. 从当前目录回退到上级目录  
cd ~:直接进入 /root  
cd / :直接进入根目录  
cd -:在两个最近命令进行跳转  
#### 6.stat
查看文件时间
#### 7.mkdir
创建目录
mkdir -p:可创建一串目录(mkdir不能)  
rmdir:删除文件(只能删除空目录，非空默认不能删)  
rm:可以删除所有文件  
rm -f:强制删除  
rm -r:删除目录
#### 8.tree
查看当前目录的树状结构
#### 9.which
查看一个命令对应的可执行文件路径
#### 10.alias
给其他命令起别名(临时别名)
#### 11. `*`
 通配符，匹配任意内容  
#### 12. man
提供命令手册，默认查第一页手册
#### 13.cp
拷贝命令  
不允许直接对目录拷贝，可以用cp -r进行目录拷贝  
cp -rf:强制拷贝  
## 知识点
- Alt+Enter:全屏，退出全屏
- 目录== 文件夹
- 文件=内容+属性
- 学习文件要么对文件操作，要么对属性操作
- ls -l显示的文件属性的第一个字符绝对，如果是d那么就是目录
- 第一个字符-开头则是普通文件
- 在Linux中以'.'开头的文件是隐藏文件，也可以隐藏目录
- win:' \ '是路径分隔符  Linux:'/'是路径分隔符
- Linux中任何一个目录都默认带"." "..",前者是当前目录，后者是上级目录
- " / "是Linux根目录
- Linux的文件结构是一颗从根目录开始的多叉树:叶子节点一定是普通文件or空目录，非叶子节点一定是非空目录
- 从根目录一直定位到目标的路径叫绝对路径
- 以非root目录为起始位置定位的文件称作相对路径
- ~:当前用户自己的家目录
- 文件有 A C M三个时间，分别是最近被访问，最后一次修改内容时间，最后一次修改文件属性时间
- 命令本质就是系统中的普通文件，等同于C，C++程序
- ll就是ls的别名
- nano是Linux中的记事本，可以写代码
- 删除目录时隐藏目录不会被删
